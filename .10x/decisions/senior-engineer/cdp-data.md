# Senior Engineer: cdp-data
Capabilities from layers.CDPCapabilities booleans to sorted tokens. Addresses via info.Addresses / info.MgmtAddresses (net.IP -> netip.Addr, unmap v4-in-v6). Prefixes from info.IPPrefixes (net.IPNet): ones from Mask.Size(), reject 0 and over-bits, skip link-local/loopback/multicast. Management VLAN from info.CDPHello.ManagementVLAN. Fingerprint: sha256 over a length-prefixed concatenation of normalized fields to avoid ambiguity. Test frames: serialize with gopacket where possible, otherwise hand-built TLV bytes behind LLC/SNAP (OUI 00:00:0c, type 0x2000).
